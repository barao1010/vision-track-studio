O worker combinado desta distribuição é disponibilizado sob GNU GPL versão 3. O código original de ligação/controlador que indica GPL-2.0-or-later permite essa opção. As licenças e atribuições originais dos componentes são preservadas.

- Texto integral GPLv3: models/LICENSE-GPL3.txt.
- Modelo YOLOX e helper yolox.py do OpenCV Zoo: Apache-2.0, models/LICENSE-YOLOX.txt.
- OpenCV, NumPy, Requests, Python e PyInstaller preservam as próprias licenças. O empacotamento PyInstaller utiliza a exceção de bootloader.

O pacote Source contém o código correspondente, scripts de compilação e atribuições. A distribuição não é afiliada ao OBS Project nem ao OpenCV Project.
